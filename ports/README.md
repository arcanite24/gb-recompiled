# Game-specific ports

This directory holds exact-ROM port projects that are developed alongside GB
Recompiled but are structured so they can later move to their own repositories.

- [Pokémon Crystal](pokemon-crystal/README.md) is the first pilot. It targets
  the US/Europe Rev 1 ROM and explores semantic native features, mod packages,
  and native presentation beyond a generic emulator.

Port projects must not commit commercial ROMs, save files, extracted assets, or
generated sources that embed ROM content.
