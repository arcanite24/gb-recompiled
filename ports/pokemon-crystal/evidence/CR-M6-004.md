# CR-M6-004 — Ship two independent sample mods

## Result

PASS. The port now ships two ROM-free, separately versioned, independently
useful data-mod packages:

- `org.gbrecompiled.crystal.route29-level-five@1.0.0` raises all 21 Route 29
  encounter slots to level 5 while preserving the original species and
  time-of-day roster;
- `org.gbrecompiled.crystal.route29-encounter-guide@1.0.0` replaces the west
  Route 29 sign with project-authored day/night encounter information and
  changes no gameplay rule.

Both work alone and together in the same previously generated executable.
Reverse manifest argument order reproduced byte-identical resolution,
artifact, and compile-report bytes. Declared conflicts fail during package
validation; unannounced semantic overlap fails during compilation with the
stable identity, byte offset, and both package/content IDs. Removing the
combined artifact restored the vanilla route and accepted the exact same save.

Two failure modes were captured before guest execution:

- a manifest-declared conflict reports the installed package ID and produces
  no resolution;
- two otherwise valid packages claiming the west sign report
  `information-sign:ROUTE_29:WEST_SIGN`, physical offset `0x1a15b9`, and both
  package/content IDs.

Both exited nonzero. The semantic collision removed deliberately planted stale
artifact and report files, so callers cannot mistake a prior successful output
for the rejected set.

## Limits and next work

- The initial information surface intentionally supports one reviewed sign and
  a small uppercase character set. Expanding text locations or encoding
  requires a new reviewed semantic mapping.
- The samples are data-only. CR-M6-005 must identify one real feature that
  cannot be represented as an overlay before considering additional native
  module composition or dynamic loading.
