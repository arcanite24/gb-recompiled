## Recompiler and runtime work

- Native patchability now uses a cached reverse-reachability index over the IR
  program. A reviewed entry remains patchable when aggressive analysis splits
  its generated body into wrapper fragments, provided it reaches `RET` and
  cannot reach `RETI`.
- Native manifests may opt a verified ROM trampoline into
  `"entry_contract": "return-stack"`. Runtime dispatch then requires a
  readable WRAM/HRAM guest return frame and retains the same SP/return-PC
  validation as a generated `CALL` or `RST`.
- Generated executables expose `--native-presentation native|original`.
  Patch callbacks query that policy with
  `gb_native_use_host_presentation(call)`.
- Port ABI v1 adds the semantic `GB_PORT_INPUT_OPEN_UI` action. Headless
  evidence can schedule strictly increasing native actions with repeatable
  `--port-input-frame <frame>:<action>`.
- Route evidence records ordered native-Pokédex events, and the pair verifier
  fails closed on altered guest checkpoints, semantic state, save data,
  fallback evidence, or host-event order.

## Limits

- Headless evidence validates renderer-independent commands and semantic
  events, not host GPU pixels or keyboard-driver behavior.
- The host surface is an overlay while the generated original Pokédex remains
  active underneath it. This is intentional for the M4 contract: the original
  callee retains all guest effects.
- The surface is read-only. Transactional guest writes begin in M5.
