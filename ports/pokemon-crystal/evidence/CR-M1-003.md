## Commands

Configure and build the first fresh generation:

```bash
cmake -G Ninja \
  -C output/pokemon-crystal-m1-a/crystal-build-profile.cmake \
  -S output/pokemon-crystal-m1-a \
  -B output/pokemon-crystal-m1-a/build
ninja -C output/pokemon-crystal-m1-a/build
```

Run the clean headless smoke:

```bash
env SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy \
  output/pokemon-crystal-m1-a/build/pokemon_crystal \
  --headless \
  --no-audio \
  --limit-frames 121 \
  --dump-state logs/pokemon-crystal/CR-M1-003/original/headless-state-121.json \
  --log-file logs/pokemon-crystal/CR-M1-003/original/headless-runtime-121.log
```

Capture selected frames from the same executable through dummy SDL:

```bash
env SDL_VIDEODRIVER=dummy SDL_AUDIODRIVER=dummy SDL_RENDER_DRIVER=software \
  output/pokemon-crystal-m1-a/build/pokemon_crystal \
  --no-audio \
  --limit-frames 120 \
  --dump-frames 1,60,120 \
  --screenshot-prefix logs/pokemon-crystal/CR-M1-003/original/f
```

The untouched second generation was moved to a new path before it had any
build directory. The same configure, build, clean headless, and dummy-SDL
capture commands were then run against the relocated path.

## Limits

- The runtime's `--headless` path uses its no-presentation fast mode and does
  not currently honor frame-dump requests. Selected frames therefore come
  from a separate dummy-SDL run of the same executable; the machine-state
  result of that run matches the headless result.
- A 120-frame limit presents and can capture frame 120 while the state schema
  records 119 because the stored count is zero-based. The definitive headless
  gate uses a 121-frame limit and asserts `completed_frames >= 120`.
- This is a boot smoke, not campaign, battle, save/continue, differential, or
  hardware-oracle proof.
- The full-scan generated project remains abnormally large because of the
  analysis over-discovery documented by `CR-M1-002`.
- Desktop battery and RTC files live beside the executable. Definitive runs
  started without those files; the local persistence artifacts remain
  ignored.
