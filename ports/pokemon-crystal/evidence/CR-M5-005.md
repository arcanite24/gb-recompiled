# CR-M5-005 — Bind the verified `BillsPC` replacement

## Result

PASS. The exact Pokémon Crystal UE Rev 1 function
`gbfn:v1:0005:5668` (`BillsPC`) is now bound by the source-only native patch
`org.gbrecompiled.crystal.bills-pc`. Native presentation opens the reviewed
PC surface, while original presentation requests the generated original body
without touching the port UI. Both dispositions retain the captured guest
call frame, so the original body continues to own mapper state, timing,
farcall return behavior, and save-related safepoints.

The final original/native route pair used the same generated executable and
generation receipt. It passed 4/4 segments, 12/12 checkpoints, semantic final
state comparison, battery/RTC persistence comparison, dual save checksums,
restart/continue, and zero interpreter fallback. The binding was observed
four times: twice in `adventure` and twice in `pc-save`. The later
`restart-continue` process attached a fresh module and passed without a stale
surface or pending native call.
