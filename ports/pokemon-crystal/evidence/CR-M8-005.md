# CR-M8-005 — Controller-first Challenge Mode panel

Status: complete on 2026-08-01.

## Outcome

The exact-ROM Crystal Workbench now provides a renderer-neutral Challenge Mode
panel that can be operated with a controller. A player can enable or disable
the ruleset, change the bounded offset from -5 through +5, inspect the complete
effective rule and current inputs, and explicitly Apply or cancel the draft.
Apply affects the next battle boundary and never rewrites an active battle.

Port ABI v3 adds only the reusable host capabilities needed by this flow:
path-free access to the exact host-configuration contract and live identity, a
runtime-owned atomic Apply callback, and explicit modal input capture. The
module never receives a configuration path or direct filesystem access. The
runtime validates and serializes the candidate, atomically replaces the host
file, and publishes the live configuration only after the write succeeds.

The default desktop mapping is F2 or controller R3 for the native game panel.
Guide/Home or L3 retains the settings menu. While the panel captures input,
D-pad or left-stick navigation and A/B are delivered as semantic port actions
and withheld from the guest. A narrowly scoped preferences migration removes
only the old default R3 second-menu binding when no explicit modern game-panel
binding exists, preventing an upgrade from opening both panels at once.
