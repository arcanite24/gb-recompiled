## Gate audit

- Stable generated-runtime contract: input actions use cycle anchors, including
  compact periodic ranges whose final pulse retains its full duration.
- Malformed input: the runtime parser rejects invalid syntax atomically and the
  route validator rejects invalid action objects, escaped route paths, unsafe or
  duplicate segment IDs, out-of-range checkpoint frames, incorrect hashes,
  missing state assertions, and stale evidence directories.
- Complete Crystal route: the manifest contains exactly the 12 required
  checkpoints in order, spanning title through separate-process Continue.
- Machine-verifiable checkpoints: every checkpoint binds a selected frame to a
  SHA-256 digest; every segment also checks completed frames, 64-bit total
  cycles, battle mode, status flags, map identity, and player coordinates.
- No live input: each process receives only the rendered checked-in input
  script. The result records the exact commands and input-file hashes.
- ROM-free repository: the manifest identifies the required ROM by digest;
  checked-in inputs, validator, manifest, and this summary contain no ROM,
  generated ROM-bearing source, save, or extracted asset.
- Fresh generated behavior: the acceptance executable came from a newly
  generated project embedding the matching runtime snapshot and passed a
  separate 120-frame headless smoke before the full route.
