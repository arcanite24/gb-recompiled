# CR-M8-007 — Vanilla and save lifecycle equivalence

Status: complete on 2026-08-01.

## Outcome

Challenge Mode remains entirely outside Crystal's guest save schema. A fresh
current-runtime vanilla build and the exact-ROM Challenge build were exercised
from the same valid 32 KiB Crystal save through Continue with the following
ordered lifecycle:

1. unpatched vanilla;
2. Challenge package present but disabled by missing configuration;
3. enabled configuration;
4. enabled restart;
5. configuration removed;
6. configuration reinstalled.

Every run produced the same selected frame, the same guest state after removing
only the explicit host-configuration provenance object, the same save bytes,
and zero interpreter fallback. Enabled runs reported the exact applied
configuration identity; disabled and removed runs reported the exact absent
identity. A malformed configuration exited before state or frame evidence and
left the copied save byte-identical.
