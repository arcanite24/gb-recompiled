# CR-M4-001 — Define the versioned semantic schema

Date: 2026-07-29

## Result

PASS. Crystal now ships a versioned, exact-ROM semantic package governed by
runtime ABI `gbrecomp.semantic` version 1. Generation validates it before
creating the output tree, copies the validated package and schema into that
tree, and records both hashes in the generation receipt.

## Public read-only views

The package defines ten typed views:

1. player name;
2. map group, map number, and coordinates;
3. Johto and Kanto badges;
4. Pokédex caught and seen flags;
5. party count, species, and records;
6. active-box count and species;
7. map-group connection pointers;
8. the five MBC3 RTC registers;
9. species base-stat records; and
10. species evolution/move pointers.

Every view carries an exact memory space, bank/address or RTC selectors,
bounded width, value type, field layout, read-only policy, and provenance.

## Fail-closed rules

Validation rejects:

- unknown schema, package, or runtime ABI versions;
- a ROM identity or size other than the supported Rev 1 cartridge;
- unknown memory spaces;
- zero, overflowing, cross-window, or impossible banked ranges;
- overlapping views in the same memory space and bank;
- malformed field offsets or types;
- writable access policies; and
- missing provenance or required product views.

The focused test includes wrong-ABI, wrong-ROM, unknown-space, zero-width, and
overlap controls.

## Reproduction

```bash
python3 ports/pokemon-crystal/scripts/validate_semantic_package.py \
  --manifest ports/pokemon-crystal/semantic/package.json \
  --schema ports/pokemon-crystal/semantic/package-schema.json \
  --output logs/pokemon-crystal/CR-M4-001/validation-20260729/result.json

ctest --test-dir build \
  -R crystal_semantic_package_is_fail_closed \
  --output-on-failure

python3 ports/pokemon-crystal/scripts/generate.py \
  --output output/pokemon-crystal-m4-001-schema

cmake -G Ninja \
  -C output/pokemon-crystal-m4-001-schema/crystal-build-profile.cmake \
  -S output/pokemon-crystal-m4-001-schema \
  -B output/pokemon-crystal-m4-001-schema/build
ninja -C output/pokemon-crystal-m4-001-schema/build

python3 ports/pokemon-crystal/scripts/validate_route.py \
  --manifest ports/pokemon-crystal/route/manifest.json \
  --executable output/pokemon-crystal-m4-001-schema/build/pokemon_crystal \
  --generation-receipt \
    output/pokemon-crystal-m4-001-schema/crystal-generation.json \
  --evidence-dir logs/pokemon-crystal/CR-M4-001/route-full-20260729 \
  --fallback-policy ports/pokemon-crystal/route/fallback-policy.json

ctest --test-dir build --output-on-failure
```
