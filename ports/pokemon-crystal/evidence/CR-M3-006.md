# CR-M3-006 — Reconfirm stable hook candidates

Date: 2026-07-29

## Result

PASS, fail-closed. Six candidate IDs remain stable across ordinary
regeneration, intentionally renamed annotation symbols, and single-function
code layout. No native patch is bound. `StartMenu` and `Pokedex` do not yet
meet the complete hook gate and remain explicitly unbound; `BillsPC` and the
three save functions remain observational.

This is a successful safety result, not a claim that a native hook is ready.

## Perturbation

The control generation changes both axes that must not participate in public
identity:

- `StartMenu` and `Pokedex` receive intentionally different annotation names;
- `--single-function` changes generated code layout.

All six `gbfn:v1` IDs, physical-ROM banks, and addresses remain identical.
The perturbed project builds successfully and produces the established
120-frame guest-state hash.
