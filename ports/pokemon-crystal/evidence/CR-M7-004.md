Status: verified

and machine-readable CLI output, and its release packer emits a complete
file/runtime/ABI manifest. Crystal now ejects through a strict source
allowlist and bootstraps only from a verified compatible distribution plus a

## Regression and failure controls

The repository regression creates a fresh distribution and ejected source
tree, installs the SDK, and compares the installed CLI identity. It also
proves that:

- a modified runtime header fails at release-inventory verification and
  installs no runtime; and
- a mismatched presentation ABI fails at Crystal compatibility verification
  and installs no runtime.

The generic relocated release test and focused standalone contract both pass.
The complete 67-test root suite passed in 24.66 seconds. The final log
SHA-256 is
`05ea5b3337dc56690cc8e63ea3198965116c3c53681022bf3362d4a06f4979fe`.

```bash
python3 tools/create_gbrecomp_distribution.py \
  --gbrecomp build/bin/gbrecomp \
  --runtime runtime \
  --license LICENSE \
  --readme README.md \
  --output output/gbrecomp-crystal-sdk-0.1.0-macos-arm64-final2-20260729 \
  --platform darwin \
  --architecture arm64

python3 ports/pokemon-crystal/scripts/eject.py \
  --output output/crystal-recompiled-standalone-m7-004-final2-20260729

python3 ports/pokemon-crystal/scripts/bootstrap.py \
  --distribution ../gbrecomp-crystal-sdk-0.1.0-macos-arm64-final-20260729 \
  --fetch-references

python3 ports/pokemon-crystal/scripts/generate.py \
  --rom /path/to/Pokemon-Crystal-Rev-1.gbc \
  --output output/pokemon-crystal-standalone-route

cmake -G Ninja \
  -C output/pokemon-crystal-standalone-route/crystal-build-profile.cmake \
  -S output/pokemon-crystal-standalone-route \
  -B output/pokemon-crystal-standalone-route/build
ninja -C output/pokemon-crystal-standalone-route/build

python3 ports/pokemon-crystal/scripts/validate_route.py \
  --manifest ports/pokemon-crystal/route/manifest.json \
  --executable \
    output/pokemon-crystal-standalone-route/build/pokemon_crystal \
  --generation-receipt \
    output/pokemon-crystal-standalone-route/crystal-generation.json \
  --evidence-dir logs/CR-M7-004/standalone-vanilla-route-20260729 \
  --fallback-policy ports/pokemon-crystal/route/fallback-policy.json \
  --rtc-unix-time 1700000000
```

## Limitations

- CR-M7-004 proves one clean macOS arm64 standalone checkout. Cross-platform
  archive/relocation and clean-machine operation belong to CR-M7-006.
- First-run graphical ROM selection and machine-readable generation progress
  belong to CR-M7-005; this gate uses the explicit `--rom` CLI input.
- The generated executable remains private ROM-derived output and is not part
  of the standalone source tree or SDK distribution.
