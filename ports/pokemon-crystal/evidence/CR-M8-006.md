# CR-M8-006 — Deterministic replay controls

Status: complete on 2026-08-01.

## Outcome

Challenge Mode now has a provenance-complete version-2 route that reaches both
reviewed mutation boundaries from a clean save using only cycle-anchored
controller input. The locked `challenge-v1` configuration uses offset `-1`:
the first reviewed wild encounter is level 4 instead of level 3, the route
raises the strongest conscious party member to level 7, and the rival's
Totodile is level 6 instead of level 5.

The adventure replay retains the first 44 actions from the reviewed vanilla
input, applies the documented 150,000,000-cycle post-battle shift, and then
uses a checked-in ROM-free controller overlay. Replay preflight authenticates
the ROM, executable, generation receipt, source inventory, native ruleset,
host configuration, no-mod policy, base input, overlay, and portable seed
before creating evidence or launching guest code.

## Three-run determinism

Three clean enabled runs produced the same comparison SHA-256
`c373b03efab9f642bcb337274e1c17980b35794b099ce762515935827b88e2ba`.
All selected frames, asserted guest state, save bytes, replay projection,
generation/provenance identities, and two seconds of PCM per segment matched.
The deterministic PCM SHA-256 was
`19f0212a2c85ff556ebeb0e7ec8d5ac64299145a606f207ac650c4aab24bf73c`.

The harness intentionally excludes `.rtc` bytes from cross-run comparison:
each run starts with empty persistence and the file may contain host elapsed
time. RTC-dependent guest behavior remains fixed by the route's explicit Unix
time and ignored-persistence policy, while frames and asserted guest state are
compared. This is the existing documented deterministic evidence boundary.

`aeb9e29f0dec6b91cfb607e9298b64460ec29c4f006f54a048651b7ffde147b8`.
