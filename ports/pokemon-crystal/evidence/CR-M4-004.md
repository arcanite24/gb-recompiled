# CR-M4-004 — Ship the read-only Pokegear Workbench slice

Status: verified

Date: 2026-07-29

## Result

PASS. Crystal's exact-ROM port module now emits a complete read-only
Workbench through the renderer-independent port ABI. The final captured frame
contains current map and position, party, badges, Pokedex progress, and a
species page backed by base-data, evolution, and level-up-move records read
from the user's ROM.

Encounter tables are not part of the current semantic schema. The Workbench
therefore displays `Encounters unavailable - encounter tables are not modeled
yet`; it does not infer or fabricate acquisition information.

## Implementation

The reusable runtime work adds:

- physical-ROM reads to save-backed semantic readers when the caller supplies
  the matching user ROM;
- deterministic retention of the final bounded `GBPortFrame` in
  `--port-state`;
- an SDL/ImGui adapter for renderer-independent panel and text commands; and
- F2 delivery through the port input action instead of a platform key code in
  the module.

The generated Crystal API adds a bounded parameterized species accessor. It
validates species IDs and base-data records, follows the exact-ROM evolution
pointer table, handles all five Gen II evolution record shapes, limits
evolutions and moves, and rejects malformed pointers, methods, species, and
levels.

`crystal-workbench` version 2 emits:

- map group/number and coordinates;
- all current party species IDs;
- Johto, Kanto, and total badge counts;
- caught and seen counts;
- one page for the first party species;
- base stats, types, catch rate, and base experience;
- ROM-decoded evolution method, parameter, condition, and target; and
- up to eight ROM-decoded level-up move entries in the visible frame.

## Gate audit

- **Deterministic host presentation sourced from semantic accessors:** passed.
  The generic port frame is submitted to SDL/ImGui when graphical, retained
  as JSON when headless, and byte-identical across repeated runs. Every
  displayed game value is checked against the generated accessor result.
- **Required Crystal content:** passed. Location/position, party, badges,
  Pokedex progress, evolution, and move information are present in the
  captured frame.
- **Live and save-backed views agree:** passed. The C accessors agree between
  modes and with an independent Python decoder for every exposed field.
- **Missing/locked knowledge is honest:** passed. Encounter knowledge carries
  the explicit `CRYSTAL_KNOWLEDGE_NOT_MODELED` state and the validator rejects
  a fixture that claims availability without corresponding modeled data.

## Limits

- Species and move labels remain numeric IDs. Names are not fabricated or
  copied from the reference checkout.
- Encounter tables are deliberately not modeled in this slice and are shown
  as unavailable.
- The deterministic gate validates renderer-independent commands, not
  pixel-identical output across SDL renderers. The SDL/ImGui adapter compiled
  in both root and freshly generated builds; cross-platform visual packaging
  remains M7 work.
- This item is read-only. It does not authorize semantic writes or native PC
  operations.
