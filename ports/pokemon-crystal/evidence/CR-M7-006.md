# CR-M7-006 — Prove cross-platform packaging and relocation

Status: partial — exact-ROM package verification is complete on all supported
targets, and physical-controller acceptance is complete on macOS arm64.
Physical-controller acceptance on the remaining required host families and a
fresh cross-platform matrix for the controller-mapping fix remain open.

## Result

The unpublished private-ROM matrix at GitHub Actions run `30599871000` passed
on Linux x64, Windows x64, macOS x64, and macOS arm64 at commit `4bdcbc0`.
Every path-free report recorded the exact 2 MiB Rev 1 ROM, four route segments,
12 checkpoints, zero interpreter fallback entries, 42 applied mod entries,
and preserved save data.

A physical 8BitDo Ultimate 2C Wired Controller exposed a missing macOS SDL2
mapping during local acceptance. GB Recompiled now installs a supplemental
mapping only when SDL has no mapping for USB vendor `2dc8`, product `301d`.
The controller verifier was also corrected to inspect the runtime log written
by `--log-file`, rather than relying only on captured process output.

A fresh ROM-free macOS arm64 package built from the corrected runtime passed
the complete exact-ROM packaged verifier and the controller-only verifier
without an environment override.

## Limitations

- The four-platform matrix predates the controller-mapping/verifier fix. It
  must be repeated on the final commit before this item can close.
- Physical controller acceptance is currently proven only on macOS arm64.
  `RELEASE.md` requires a physical-device smoke for every supported host
  family.
- CR-M7-006 remains unchecked until those host-family controller results and
  the final clean-machine matrix are retained.
