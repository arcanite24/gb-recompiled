Status: verified

## Result

PASS. The complete deterministic Crystal route produced identical guest
state, checkpoint frames, deterministic PCM, battery save, RTC persistence,
and interpreter-fallback results with the port module disabled, enabled but
closed, and enabled while repeatedly opened and closed.

the four route segments and finished each segment with a non-empty native

or presentation command. Host-only state is therefore both exercised and
excluded from the guest equality projection explicitly.

## Implementation

The generated runtime accepts multiple strictly increasing
`--port-toggle-frame` options. Every scheduled toggle is delivered through
the same versioned port-input action as interactive F2 input; malformed,
duplicate, or descending schedules fail before execution.

The Crystal route validator now optionally:

- forwards an explicit, bounded list of runtime arguments without allowing
  the caller to override evidence-core flags;
- captures the final port state for every route segment;
- parses ordered native-UI shown/hidden semantic events;
- records the raw guest-state hash; and
- records final battery-save and RTC file hashes and sizes.

The cross-profile verifier compares a deliberately defined guest projection
covering route inputs, checkpoints, final state, state-file hash, PCM,
fallback evidence, and persistence. It separately requires the enabled/closed
profile to have no host activity and the interactive profile to show and hide
the Workbench at least twice per segment with a rendered final frame.

  enabled/closed, and enabled/interactive evidence is retained separately.
- **Complete route with repeated opening and closing:** passed. Each of the

  toggles while preserving all 12 canonical checkpoints.
- **Guest state, frame, PCM, save, RTC, and fallback equality:** passed. The

  regression rejects an injected guest-state mismatch.

  none participate in the guest projection.

## Limits

- The gate proves deterministic observation on the locked macOS toolchain. It
  does not claim cross-platform rendering identity.
- Scheduled toggles exercise the same port action as F2, but this headless
  route does not test host keyboard drivers.
- The Workbench remains read-only. Native replacement and write transactions
  are separate backlog items.
